# Security Policy

We take the security of `gea-a11y` seriously. This document outlines how to report vulnerabilities. As this is an open-source project maintained in my spare time, security responses are handled on a **best-effort basis**.

## Supported Versions

Only the latest major version of `gea-a11y` receives security updates.

| Version | Supported |
| --- | --- |
| 1.x | ✅ Yes |
| < 1.0.0 | ❌ No |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub Issues.**

If you discover a security vulnerability within this project, please report it via GitHub Private Vulnerability Reporting:

* **Contact**: [KoHaRxnP](https://github.com/KoHaRxnP)

### What to Include

When reporting a vulnerability, please provide:

* A description of the vulnerability and its potential impact.
* Steps to reproduce or a minimal working example.

## Our Process

1. **Investigation**: We will look into the issue as soon as time permits.
2. **Fix & Release**: Once verified, a patch will be released. You will be credited for the discovery if you wish.
